# BizBerry Wandoor Product Images

This repository contains 114 current transparent menu PNGs across 21 categories, organized under images/ by category.

- [Find a product image and its editing prompt](prompts/README.md)
- [Image catalog, credits and source licenses](image-catalog.csv)
- [Original prompts and revision notes](image-prompts.txt)
- [Burgundy preview](preview.html) for a local checkout or the downloaded repository ZIP

## Use another image model

1. Download the current PNG for your item.
2. Attach the PNG to your image model and paste the matching prompt.
3. Replace the bracketed line with your specific change. Attach any additional photo references for that change.
4. Export a transparent square PNG for the burgundy menu.

The collection includes product mockups and edited stock photos. Source credits and applicable license links are in the catalog.
